PNL Séance

Assistant de séance PNL · Yann Fréhel

Installez l’assistant sur votre téléphone en une minute. Il s’ouvrira ensuite depuis votre écran d’accueil, en plein écran, comme une application.

Ce lien s’est ouvert à l’intérieur d’une autre application, qui ne permet pas l’installation. Ouvrez-le dans votre navigateur : touchez le menu de cette fenêtre puis « Ouvrir dans le navigateur », ou copiez le lien.
  1. Touchez le bouton ci-dessous pour ouvrir l’appli dans Safari. Ouvrir PNL Séance
  2. Touchez le bouton de partage , en bas de l’écran (en haut sur iPad).
  3. Faites défiler la liste et touchez « Sur l’écran d’accueil ».
  4. Touchez « Ajouter » en haut à droite.
  5. Ouvrez PNL Séance depuis votre écran d’accueil et connectez-vous avec les identifiants que vous avez reçus.

Ces étapes sont rappelées sur l’écran de connexion de l’appli.

  1. Touchez le bouton ci-dessous pour ouvrir l’appli dans Chrome. Ouvrir PNL Séance
  2. Sur l’écran de connexion, touchez « Installer l’appli » si le bouton apparaît. Sinon, ouvrez le menu en haut à droite, puis « Installer l’application » ou « Ajouter à l’écran d’accueil ».
  3. Confirmez avec « Installer ».
  4. Ouvrez PNL Séance depuis votre écran d’accueil et connectez-vous avec les identifiants que vous avez reçus.

Avec Samsung Internet : menu ≡, puis « Ajouter la page à », puis « Écran d’accueil ».

  1. Scannez ce code avec l’appareil photo de votre téléphone pour ouvrir cette page.
